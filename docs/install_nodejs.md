# Node.js インストールガイド

本ガイドでは、Terraria Recipe Viewer をローカル環境で起動・開発するために必要な **Node.js** のインストール手順を説明します。

---

## 📥 1. インストーラーのダウンロード

1. [Node.js 公式サイト (日本語)](https://nodejs.org/ja) にアクセスします。
2. トップページの **「Node.js® を入手」** をクリックします。
3. Windows用の **LTS（推奨版）インストーラー (`.msi` / x64)** をダウンロードします。

![Node.js インストーラーのダウンロード](./picture/install_node_js.png)

---

## ⚙️ 2. インストール手順

1. ダウンロードした `.msi` ファイルを実行します。
2. セットアップウィザードが表示されるので、すべてデフォルトのまま **「Next」** を進めてインストールを完了させます。

---

## ✅ 3. インストールの確認

1. スタートメニューまたは検索バーから **「コマンドプロンプト」** または **「PowerShell」** を起動します。
2. 以下の2つのコマンドを実行します：

```bash
node -v
npm -v
```

3. 正常にインストールされている場合、以下のようにバージョン番号が表示されます：

![Node.js バージョン確認画面](./picture/node_js_version.png)

> [!NOTE]
> コマンドを実行してもバージョンが表示されない（`'node' は内部コマンドまたは外部コマンド...` と表示される）場合は、コマンドプロンプトを一度閉じて再起動するか、PC を再起動してください。

---

## 🚀 次のステップ

Node.js のインストールが完了したら、[README.md](../README.md#💻-開発ローカル起動手順) に戻り、以下のコマンドで Web ビューアーを起動してください：

```bash
# 依存パッケージのインストール
npm install

# 開発サーバーの起動
npm run dev
```
